# 💳 Credit Card Project – Machine Learning

## 📌 Project Overview

This project focuses on analyzing **credit card customer data** using Python and applying **Machine Learning techniques** to build and evaluate a predictive model.

The project covers the complete workflow from **data preprocessing and exploratory data analysis (EDA) to machine learning model building and evaluation**.

---

## 🎯 Objectives

* Understand and analyze the credit card dataset.
* Perform data cleaning and preprocessing.
* Explore relationships between different variables.
* Handle categorical variables using encoding techniques.
* Analyze correlations between features.
* Prepare the dataset for Machine Learning.
* Build a Machine Learning model.
* Evaluate the performance of the model using suitable evaluation metrics.

---

## 📂 Project Workflow

### 1. Data Collection

The credit card dataset was imported into Python for analysis.

### 2. Data Preprocessing

The dataset was checked and prepared by:

* Understanding the dataset
* Checking data types
* Handling missing values
* Removing unnecessary columns
* Checking duplicate values
* Identifying categorical and numerical variables

### 3. Exploratory Data Analysis

Exploratory Data Analysis was performed to understand the dataset using:

* Descriptive statistics
* Data distributions
* Graphical visualizations
* Feature analysis
* Correlation analysis

### 4. Data Encoding

Categorical variables were converted into numerical form using encoding techniques such as:

* One-Hot Encoding
* Label Encoding

This helped prepare categorical data for Machine Learning algorithms.

### 5. Correlation Analysis

Correlation analysis was performed to understand the relationship between different numerical features.

A correlation matrix and heatmap were used to identify relationships among variables.

### 6. Machine Learning

After preprocessing and feature preparation, the dataset was divided into:

* **Training Data**
* **Testing Data**

A Machine Learning model was then trained using the training dataset.

### 7. Model Evaluation

The trained model was evaluated using appropriate performance metrics.

Evaluation helps determine how well the model performs on unseen test data.

---

## 📊 Machine Learning Model

The project includes:

* Feature selection
* Train-test split
* Model training
* Prediction
* Model evaluation

### Evaluation Metrics

Depending on the model and target variable, evaluation can include:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
